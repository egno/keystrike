# Keystrike Wiki

Documentation for [Keystrike](https://github.com/egno/keystrike) — an offline terminal typing tutor with adaptive drills and per-layout stats.

## Guides

- **[Git sync](Git-sync)** — back up and sync settings and sessions via a private git repository (CLI-only, opt-in).
- **[Word lists](Word-Lists)** — import a remote dictionary for real-word adaptive drills (Settings, optional).
- **[Confidence tuning](Confidence-Tuning)** — session window and attempt floors for unlocks, focus, and the stats heatmap.
